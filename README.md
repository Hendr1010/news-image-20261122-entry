# Sunday 22 November 2026 — The World in One Day

One image that sums up the world's news of Sunday 22 November 2026: 35 stories
across 7 regions, every one dated that day.

The front page leads with the three stories that moved the day — Russia's
186-drone night over Ukraine, the COP31 climate deal that names no fossil
fuels, and Iran's claim of strikes on US radars in Bahrain against Bahrain's
denial — then ten more stories, a world map with numbered pins, and 22 more
stories below. A date check at the foot of the page names what was left out
on purpose: events from other days, so the picture is one day's news only.

The image is drawn in code (Python + Pillow, run at build time) and committed
as `entry.png`. The program itself is a one-step Node script that copies it to
`/output/entry.png`.
